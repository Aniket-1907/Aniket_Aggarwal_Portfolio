# Aniket Aggarwal Portfolio

A responsive single-page portfolio for Aniket Aggarwal, Senior Analyst / Java-Spring Boot backend engineer.

## Run locally
Open `index.html` directly in a browser, or run:
- `python -m http.server 8000`
- then visit `http://localhost:8000`

## Before publishing
Replace:
- `YOUR_EMAIL@example.com`
- LinkedIn URL
- GitHub URL
- Fiverr profile URL (replace `https://www.fiverr.com/yourusername` in `index.html`)

The content intentionally excludes private information such as date of birth, health information, and personal phone number.


## LeetCode and resume
- The LeetCode links point to https://leetcode.com/u/AniketAgg1907/.
- Put your resume PDF in this same folder and name it `resume.pdf`. The Download Resume buttons will then download it as `Aniket_Aggarwal_Resume.pdf`.
- Do not publish until you have added the actual resume PDF if you want the download button to work.


## Mobile layout
The stylesheet includes responsive refinements for narrow screens, flexible buttons, and content overflow.

## Fiverr web-development section
The freelance website-development section is separate from the Contact section. Replace the placeholder Fiverr URL before publishing.
