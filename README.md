# Aniket Aggarwal — Portfolio

A responsive, single-page personal portfolio showcasing my professional profile as a Java and Spring Boot backend developer.

🌐 **Live Website:** [aniketagg.in](https://aniketagg.in)

## About the Website

The portfolio presents my professional background, technical expertise, and development work in one place.

### Sections

- **About Me** — Professional introduction and career profile.
- **Technical Skills** — Programming languages, frameworks, databases, and tools.
- **Experience** — Professional experience and key responsibilities.
- **Projects** — Selected development projects.
- **Education & Certifications** — Academic background and certifications.
- **LeetCode** — Coding practice and problem-solving profile.
- **Freelance Services** — Website development services.
- **Contact** — Ways to connect with me.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

```bash
git clone https://github.com/Aniket-1907/Aniket_Aggarwal_Portfolio.git
cd Aniket_Aggarwal_Portfolio
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

Alternatively, open `index.html` directly.
